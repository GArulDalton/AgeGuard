# Results

Headline results of the paper. The full numbers are regenerated by `evaluate.py` (Tables 2–7) and `recalibration.py` (Tables 8–9). `recal.pkl` in this folder holds the recalibration results.

## Main comparison (Table 2): K = 20, v_max = 30 km/h, ε = 0.05, S = 64, 200 test networks

| Method | Sum goodput (bps/Hz) | Avg. outage |
|---|---|---|
| Full power, naive rate | 30.44 | 0.500 |
| WMMSE on aged CSI, naive rate | 37.26 | 0.529 |
| Full power + safety layer | 44.35 | 0.045 |
| WMMSE + safety layer | 59.72 | 0.046 |
| Age-aware WMMSE + safety layer | 59.50 | 0.046 |
| GNN trained on perfect CSI + safety layer | 60.58 | 0.046 |
| Per-instance optimizer (Q-Opt) | 60.97 | 0.046 |
| **AgeGuard** | **61.65** | **0.046** |
